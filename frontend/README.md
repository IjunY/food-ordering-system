# 清大點餐 前端（收據版）

純 HTML/CSS/JS，不用建置。

## 怎麼打開

**接真後端**（建議）：照根目錄 README 啟動後端，開 http://127.0.0.1:8000 。後端會直接提供這個資料夾。

**只看畫面**（全部假資料）：

```bash
python -m http.server 5174 -d frontend
```

開 http://127.0.0.1:5174 。

開機時前端會呼叫 `GET /api/health`，有回 `{"status":"ok"}` 就用真後端，沒有就自動改用假資料（`js/mock/`）。

## 哪些接了真後端

| 功能 | 真後端模式 | 說明 |
|---|---|---|
| 註冊、登入、我的資料 | 真的 | `/api/auth/*`；註冊頁是新加的 |
| 下單、我的訂單、訂單進度 | 真的 | `/api/orders` |
| 店家接單看板（接單、完成、已取餐、拒單） | 真的 | `/api/orders/{id}/status`、`/cancel` |
| 餐廳列表、菜單、品項頁、等候時間 | 假資料 | 菜單仍顯示示範資料；下單時用「餐廳中文名＋品項中文名」換成資料庫的品項編號 |
| 付款 | 模擬 | 一律成功，付款紀錄只存在這台瀏覽器 |
| 店家設定、菜單管理、報表、平台管理、上傳照片 | 假資料 | |

轉接層在 `js/real/api.js`：呼叫後端，再把回傳轉成畫面用的欄位（和 `js/mock/api.js` 同一套）。

已知限制（後端還沒有對應欄位）：
- 加點選項（辣度、加蛋）與備註不會存進後端，金額以後端的菜單價格為準
- 店家帳號一律管示範的第一家餐廳（水木自助餐），後端還沒有「店家屬於哪家餐廳」
- 取餐號碼用訂單編號（A044）；預計完成時間是前端估的
- 菜單示範資料（`js/mock/data.js`）和 `scripts/demo_menu.json` 要列一樣的名稱，改一邊要記得改另一邊

## 假資料模式

網址參數只在假資料模式有效：`?as=customer|staff|admin` 直接登入、`?lang=en` 切英文、`?reset=1` 清掉示範資料。
假資料存在瀏覽器的 `mockdb_v2` 欄位。

## 設計方向

- 調性：收據／取餐票。暖白收據紙、近黑墨色、虛線分隔、等寬數字（IBM Plex Mono）
- 清華紫只用在：主要按鈕、選取中的分頁、取餐號碼、「可取餐」通知
- 沒有圖片框、沒有圖示裝飾、沒有圓角卡片、沒有彩色狀態徽章；狀態用文字
- 每個畫面一個主角：首頁＝等候看板、餐廳頁＝印刷菜單（品名……價格）、購物車＝收據、付款完成／進度＝取餐票、店家＝廚房票軌
- 深色模式跟著系統設定

## 和舊版不同的地方

| 項目 | 舊版 | v2 |
|---|---|---|
| 餐廳列表 | 灰色圖片框＋彩色等候標籤 | 等候分鐘數大字靠右，像時刻表 |
| 菜單 | 圖片框＋紫色加號 | 品名、點點引線、價格 |
| 購物車 | 白色卡片 | 收據（單價、數量、合計） |
| 取餐號碼 | 置中大字卡片 | 有撕線的取餐票 |
| 訂單進度 | 圓點步驟條 | 時間＋步驟的列印紀錄 |
| 店家後台 | 左側選單＋卡片 | 上方選單＋廚房票 |
| 載入／錯誤 | 只有提示訊息 | 載入超過 0.2 秒出現骨架；載入失敗有「重新載入」 |

## 檔案

```
frontend/
  index.html
  css/tokens.css   顏色、字型、間距（含深色模式）
  css/base.css     基本規則
  css/app.css      全部畫面樣式（開頭是 Hallmark 設計檢查紀錄）
  js/components.js 元件（重寫）
  js/pages/        顧客端、店家端畫面（重寫）
  js/icons.js      只剩返回、加減、關閉四個圖示
  js/api.js        資料入口：開機判斷真後端／假資料，再分給 real/ 或 mock/
  js/real/api.js   真後端轉接層
  js/mock/         假資料與假後端
  js/store.js、router.js、main.js、i18n.js
```

## 照片

| 位置 | 欄位 | 比例 | 在哪裡上傳 |
|---|---|---|---|
| 首頁列表小圖 | `restaurant.image_url` | 方形 | 店家設定 |
| 餐廳頁封面 | `restaurant.cover_image_url` | 16:9 | 店家設定 |
| 菜單每一列、品項頁大圖 | `menu_item.image_url` | 方形縮圖／4:3 | 菜單管理的編輯視窗 |
| 後台菜單表、平台餐廳表 | 同上 | 小方形 | |

- 沒有照片時顯示虛線框「照片」，上傳後自動換成照片
- 假後端把照片縮到長邊 720px 存在瀏覽器裡（localStorage 約 5 MB 上限，大約能放 30 張）
- 真後端還沒有上傳功能；之後要做一支 `POST /api/uploads`（multipart，欄位名 `file`），回傳 `{ "url": "..." }`
